# Telegram Order Bot 🤖

Telegram-бот для управления заказами.

## Стек

- Python 3.14
- aiogram
- SQLite
- Docker
- Docker Compose

## Возможности

- Работа с Telegram-командами и сообщениями
- Создание и обработка заказов
- Хранение заказов в SQLite
- Получение статистики
- Работа через Telegram Bot API
